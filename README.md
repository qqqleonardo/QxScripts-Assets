# QxScripts Assets

Public image assets for [QxScripts](https://codeberg.org/chambers/QxScripts), primarily used by Quantumult X Gallery and BoxJS.

## Structure

- `icons/` — mini-program and service icons

## Raw URL

```text
https://raw.githubusercontent.com/qqqleonardo/QxScripts-Assets/main/icons/<Name>.png
```

Only public brand/application artwork belongs here. Do not commit credentials, captures, `.wxapkg` files, unpacked mini-program source, QR codes, or user data.
